A faster drop-in for make.fun's own csv-reader 1.0.0: it returns exactly csv-reader's answer for every input, faster. `solve.js` reads each CSV text once, left to right, with csv-reader's broken-row policy (stray CRs, unterminated quotes, quote junk, short and long rows), splitting quote-free records natively and scanning quoted fields with native jumps instead of one character at a time.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`) and writes the answers to `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
